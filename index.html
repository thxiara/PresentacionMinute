Administración de Sistemas

Relevamiento e Infraestructura

Desplegado sobre el sistema operativo OpenSUSE dentro de un VPS contratado en VPSDime.

  • OpenSUSE: Abundancia de documentación y modelo de versionado rolling release (versión única en constante actualización sin pérdida de soporte).
  • VPSDime: Bajo costo de operación respecto a la competencia manteniendo calidad y soporte nativo para OpenSUSE.

Configuración del Sistema

Filosofía de Menor Privilegio

Cada usuario, servicio y proceso posee estrictamente los permisos indispensables para cumplir su función.

Esta lógica se extiende al tráfico de datos: los procesos internos deben ser habilitados manualmente para emitir o recibir información. Así, en caso de vulnerabilidad, se mitiga drásticamente el radio de impacto.

Servicios Utilizados

Apache

Motor web sobre el cual corre la aplicación, actuando como intermediario entre los procesos del sistema.

MariaDB

Servidor de base de datos encargado de almacenar y organizar la información ingresada por los usuarios.

Copias de Seguridad

Sistema de Backups

Mecanismo automatizado que garantiza la disponibilidad de la base de datos ante cualquier eventualidad, respaldando la información periódicamente de forma local y en la nube.

Además de las tareas programadas, los usuarios habilitados pueden ejecutar respaldos manuales a demanda.

Centro de Cómputos (ABML)

Interfaz de Administración

Herramienta gráfica desarrollada para facilitar tareas operativas a usuarios sin conocimientos técnicos avanzados.

Permite administrar la actualización de la aplicación web y la gestión integral de copias de seguridad de forma amigable e intuitiva.
